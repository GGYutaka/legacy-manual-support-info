# レガシー整備書サポート (Legacy Manual Support)

[FAINES](https://faines.jaspa.or.jp/) に掲載されている古い整備書を、Chrome でそのまま閲覧できるようにする非公式の拡張機能です。

> **非公式ツールです。** 一般社団法人 日本自動車整備振興会連合会 (JASPA)・FAINES とは関係ありません。
> FAINES を使うには、これまでどおり会員としてのログインが必要です。
> この拡張機能は表示を補うだけで、整備書の内容 (PDF・画像・本文) は一切含みません。また、資料をダウンロード・保存する機能もありません。
>
> **使用に関する一切の責任は使用者にあります。** 作者は、使用によって生じたいかなる損害についても責任を負いません。
> インストール・使用の前に [利用規約](TERMS.md) を確認してください。[プライバシーポリシー](PRIVACY.md)

## できること

| 症状 | 対応 |
|---|---|
| 「情報表示」を押しても何も出ない／白紙になる (日産ESMなど、Internet Explorer専用の閲覧画面) | IE専用の機能 (ActiveXのXML読み込み・Scripting.Dictionary・document.frames・attachEvent・selectNodes など) を Chrome 用に補います |
| PDFの表紙しか見られない、しおり・目次から章へ飛べない (トヨタ旧PDF形式など、章ごとに別PDFへリンクしている資料) | FAINESのPDFを専用ビューアで開き、別PDFへのしおり・リンクを辿れるようにします (戻る/進む・文書内検索・しおり表示付き) |
| 開いた直後に出るはずの別ウィンドウがポップアップブロックで出ない | 同じタブで開きます |
| 「Internet Explorer で実行してください」と表示されて閉じる／一覧が空のまま | その資料だけ Internet Explorer として振る舞い、読み込み直します |
| Mac などで「お使いのマシンでは、本システムはご利用になれません」と出る (Windows 以外を弾く旧形式) | その資料だけ Windows として振る舞い、読み込み直します |
| 目次の項目が重なって表示される／本文側が「ダウンロードしています」のまま進まない (Netscape 4 用の目次に振り分けられる旧形式) | IE用の目次に振り分け直します |

### 対応している資料の形式

| 形式 | 状態 |
|---|---|
| IE専用の閲覧画面 (ActiveX・XMLで目次を組み立てる旧形式の電子整備書) | 表示できることを確認 |
| 章ごとに別PDFへリンクしているPDF形式の整備書 | しおり・リンクで別PDFへ移動できることを確認 |
| 開くと「Internet Explorer で実行してください」と出て止まる旧形式 (ブラウザ名・OSを確認するもの) | IEとして振る舞い、選択画面・目次・本文まで表示できることを確認 |
| ブラウザ名で IE用 / Netscape 4 用の目次を出し分けるフレーム形式 | IE用の目次に切り替え、目次・本文・配線図まで表示できることを確認 |
| Chrome でそのまま開ける新しい閲覧画面・PDF | 影響がないことを確認 |

表示できない資料があった場合は、[報告](#表示できない資料の報告) をお願いします。

## インストール

1. パソコンの Chrome で、Chrome ウェブストアの「レガシー整備書サポート」のページを開きます (URL は配布元から案内します)。
2. 「Chrome に追加」→「拡張機能を追加」を押します。
3. ツールバーのパズルのアイコンから「レガシー整備書サポート」をピン留めしておくと、設定を切り替えやすくなります。

更新は Chrome が自動で行います。

以前に ZIP から「パッケージ化されていない拡張機能」として入れた場合は、`chrome://extensions` で古いほうを削除してから、ストア版を入れてください (両方あると同じ処理が二重に動きます)。

## 使い方

いつもどおり FAINES にログインして資料を開くだけです。

- PDFは専用ビューアで開きます。左のしおりの「↗」は別のPDFへ飛ぶ項目です。上部の ◀ ▶ で前に見ていたPDFへ戻れます。
- Chrome 標準の PDF 表示に切り替えたいときは、右上の「標準表示」を押します。
- 拡張機能アイコンのメニューで、IE互換モードとPDFビューアをそれぞれオン/オフできます。

## うまく表示されないとき

- IE互換は、資料ごとに「IE専用の機能が必要か」を自動で判定して記憶します。表示が崩れた場合は、その資料を開いた状態で拡張機能メニューの「IEモード記録をリセット」を押し、ページを再読み込みしてください。
- FAINES がメンテナンス中のときは資料を開けません。
- VBScript で作られた画面や、ActiveXの専用プラグイン (CADビューア等) が必要な画面には対応できません。

### 表示できない資料の報告

資料を開いた状態で拡張機能メニューの「表示されない資料を報告」を押すと、ページのURLが入った報告フォーム (GitHub Issue) が開きます。
メーカー・車名・型式と症状を書いて送ってください (GitHub アカウントが必要です)。
**資料の画面写真や本文は FAINES の著作物なので貼らないでください。**
